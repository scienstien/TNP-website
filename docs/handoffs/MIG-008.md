## Scope statement
Connect calendar UI to existing drive_events/event_roles with authenticated reads, SUPERADMIN/chosen-department transactional writes, nullable dates, exact drive/role IDs, preserved browser entries and pure tests. No schema/migration/navigation changes.

## Summary of behavior change (before → after, user-visible and data-level)
The calendar formerly edited department-keyed browser-only free text. It now reads shared PostgreSQL events for the visible month plus all undated events; exact-drive event forms persist canonical stages and atomic role sets. Browser entries remain unchanged in a labelled read-only panel with raw JSON export. Refresh loads other browsers' saves; no realtime claim.

## Contracts introduced or changed (exact TypeScript)
```ts
interface CalendarWindow { startsOn: string; endsOn: string }
interface CalendarEvent {
  eventId: string; driveId: string; companyId: string; companyName: string;
  cycleId: string; cycleCode: string; driveReference: string | null;
  processType: "PPT" | "OT" | "GD" | "RESUME_SHORTLISTING" | "PI";
  scheduledDate: string | null; scope: "WHOLE_DRIVE" | "SELECTED_ROLES";
  label: string | null; roles: { roleId: string; jobTitle: string | null }[];
}
interface EventInput {
  driveId: string; processType: CalendarEvent["processType"];
  scheduledDate: string | null; scope: CalendarEvent["scope"];
  label: string | null; roleIds: string[];
}
interface EventResult { ok?: true; error?: string }
getCalendarData(window: CalendarWindow): Promise<CalendarEvent[]>
createEvent(input: unknown): Promise<EventResult>
updateEvent(eventId: unknown, input: unknown, expected: unknown): Promise<EventResult>
deleteEvent(eventId: unknown, expected: unknown): Promise<EventResult>
```
expected = JSON.stringify(CalendarEvent) with roles ordered title asc nulls last, roleId asc. No cross-lane contract change: visitDatesByCompany, todayInInstituteZone and isValidIsoDate are unchanged. lib/calendar/dates.ts is untouched.
