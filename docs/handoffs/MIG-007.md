## Contracts introduced or changed (exact TypeScript)
### Contracts
```ts
export interface DriveRoleOption {
  roleId: string;
  jobTitle: string | null;
}
export interface DriveOption {
  driveId: string;
  companyId: string;
  companyName: string;
  cycleId: string;
  cycleCode: string;
  reference: string | null;
  roles: DriveRoleOption[];
}
export interface DriveOptionFilter {
  companyId?: string;
  cycleId?: string;
}
export interface DriveResult { ok?: true; error?: string }

// read.ts; server-only; callers authorize before calling; supports transactions.
export async function readDriveOptions(connection: Database | Transaction, filter: DriveOptionFilter): Promise<DriveOption[]>;
// queries.ts; server-only; requireRole("ADMIN"); invalid UUID filters => [].
export async function getDriveOptions(filter: DriveOptionFilter): Promise<DriveOption[]>;
export async function getDriveCompanies(): Promise<{ companyId: string; name: string }[]>;
// actions.ts; each rechecks SUPERADMIN + resolved non-null department.
export async function createDrive(input: unknown): Promise<DriveResult>;
export async function updateDrive(driveId: unknown, input: unknown, expected: unknown): Promise<DriveResult>;
export async function deleteDrive(driveId: unknown, expected: unknown): Promise<DriveResult>;
export async function createRole(input: unknown): Promise<DriveResult>;
export async function updateRole(roleId: unknown, input: unknown, expected: unknown): Promise<DriveResult>;
export async function deleteRole(roleId: unknown, expected: unknown): Promise<DriveResult>;
```
Read contract has **no deviations** from the owner's section 5. Drive create payload { companyId, cycleId, reference }; drive update { reference }; role create { driveId, jobTitle }; role update { jobTitle }. expected is JSON.stringify(DriveOption) or JSON.stringify(DriveRoleOption). Blank optional text maps to null; omitted update text clears it.
